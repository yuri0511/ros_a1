## 十、launch 默认档:裸命令 = 双臂并联 8 件(用户拍板)

实现 = 三个参数改 **auto 哨兵档**(未显式传时联动解析;显式值/
显式空串一律尊重):
- `dual_arm:=auto` → `pipeline ? true : false`。legacy
  (`pipeline:=false`)自动单臂,batch 三件基线零差(实测:调度器
  "单臂"、无 relay 节点)。
- `arm2_colors:=auto` → 双臂+pipeline 时 `red,green`(v2 定案)。
  经典接力逃生门 = 显式 `arm2_colors:=""`(launch 区分不了
  "未传"与"显式空",故必须用哨兵词,不能用空串兼职)。
- `random_colors:=auto` → 双臂四色全上;单臂自动收窄
  `blue,yellow`(根治"四色裸跑红绿派 arm1 必 unknown_category")。
- `demo_parts` 0→8。

依赖点同步钉死(防静默翻转):run_acceptance pipeline/legacy 模式
显式 `dual_arm:=false`;mcp_ros2_cell 单臂预设、ros2_mcp_server
launch_demo 同。踩到的真 bug:`ParameterValue('true', value_type=bool)`
直传字符串字面量当场 TypeError(旧代码传 LaunchConfiguration 靠
延迟转型才没炸)——解析后的确定值直接给 Python bool。

## 十一、观感①:出生态"一闭一张"= effort 夹爪无指令自由漂

用户截图:右臂出生时左指闭右指开。隔离实验(cell_bringup 单会话
无任务)定罪:

1. **出生态**:夹爪纯 effort 控制、无初始指令,两指不受力,被推向
   **相反**限位且**两臂镜像**(arm1 L=-0.003/R=+0.040,arm2 反之,
   两臂基座朝向相反所致)。干过活的臂末条指令=全开,两指对称停
   开限位,所以"看起来正常"。xacro 的 ros2_control 块没有
   initial_position 通道(gz_ros2_control 不支持),执行器侧是唯一
   零物理改动的修法。
2. **单发指令会丢**(同实验第二发现):新建 publisher 单发 +8N,
   3s 后指位不动;持续发布则两指对称响应。DDS 首发布与控制器
   订阅发现竞态。旧 `_grip` 每段只发一次 → 丢包段整段退化为
   "指不受力自由漂"。

修复(c052631):`__init__` 起 10Hz `_grip_hold_tick` 重发最近一次
力值(初值=全开,兼作启动归位);所有命令统一走
`_pub_gripper_cmd`(记保持值+立即发)。同值重发对 effort 控制器
幂等,零物理差。实机:启动后四指全部 +0.0400 对称。

## 十二、观感②:放置"顶盒沿"= 箱底全开插壁带 43mm

几何账(外格;格心 y 偏 ±0.05 = G0 锚表定值,红线不动):
指外缘到夹爪轴 = 0.038+q。闭爪持件 q=-0.003 → 到箱心 0.085,
恰好贴壁内缘(0mm);**全开 q=+0.040 → 0.128,插进壁带 43mm**。
旧释放序列在**箱底**就"1.5N 慢开 1.2s → 8N 全开"(阻尼 15 下
1.5N 末速 0.1m/s,1.2s 足够冲满限位),随后**张着满爪穿过 95mm
壁高抬臂** = 肉眼顶沿刮擦。

修复(c052631):`fingers_released` 纯函数 + `_open_to_release_gap`
位置闸(bang-bang:低于目标 +1.5N 外推/带内 0N/超带 -1.5N 内收,
保持交 10Hz 定时器)→ 小开到刚脱件(q≈0.001,内隙 54mm>工件
50mm)→ **保持小开**抬臂出箱 → `settle_rise` 之后(箱沿之上)
才全开。超时不再箱底强推,卸荷保持当前开度(严格优于旧行为)。
软闸口径同 P2:键查不到/中途消失/超时均不抛,零新增失败路径。

## 十三、新定罪:抓取期单指钉死(pre-existing,本批不修)

裸命令轮稳定指纹:`两指停稳 L=-0.0030 R=+0.0400`(arm1)/
镜像(arm2)——**闭爪全程一侧指被钉在开限位不动**,另一指独走
43mm 到闭限位。sync_cap 的"单侧先行 15-16mm"是同一现象的
轻触段表现。证据链:
- 无件隔离实验两指对称闭合 → 不是丢命令、不是控制器问题;
- P2 闸旧日志(定档时点)同指纹 → **早于本批存在**,非回归;
- 钉死侧两臂镜像 = 带面同一世界侧;疑与带侧壁(y∈±0.08,满开
  指外缘 0.078 仅 2mm 余量)+ mu=2 指面摩擦/件偏心相关。

影响:① 释放闸 5/8 超时走卸荷兜底(兜底仍严格优于旧行为);
② 残余观感来源;③ 梯级失速(z≈1.04)部分相关。
候选专项(涉物理定档,须另立任务+单变量闸):带侧壁收窄、
指面摩擦下调、取件 y 偏置、轻触段起始预开度。

## 十五、用户复诉①"还没闭合就抬臂"——比 §十三 更深一层,已根治(207afc7)

用户判据(拍板):**左右夹手都闭合 + 确认物块夹住,才准抬机械臂**。
§十三 的"单指钉死"在实机观感上正是这条:停稳闸放行时一指根本没碰件。
本批把判据落成硬闸链,并顺藤摸到钉死的最终机制。

### 定罪链(三层遥测,证据 docs/evidence/20261009/clamp_gate/)

1. **effort 层**(481k 行,138Hz):轻触段钉死侧 -32~-81N 反力、位不动;
   锁紧段两指竟对称收敛(限位反力消失)→ 钉死源不是关节限位本身。
2. **TF 层**:arm1 tool0 最低 0.954 是**放置**触底窗(首轮误读),取件窗
   tool0 1.011,指尖离带 27mm——"扎带面"假设当场证伪一半。
3. **同步层**(tools/tmp_sync_track.py:指位+间隙+夹爪基座+全部工件世界
   xy,同一时间轴):钉死瞬间工件**在正中心**(偏心 1mm)、指跨中心
   与工件重合、一指冻结在 +0.0242(**非限位!±8N 双向都拉不动**)、
   全开脉冲也拉不开、**抬臂离带瞬间弹回**——接触冻结实锤。
   几何账:指尖=tool0−0.231=0.778 **扎进带顶 0.780 达 2mm**
   (tcp_z 0.204 vs 指尖 0.231 的 27mm 里,碰撞盒 0.030-0.060 段
   穿带),指面 mu=2.0 对带静摩擦 ≫ 闭爪命令全域 → 蹭到哪冻到哪。
4. 对中假设实测否决(锚 PTP 落点偏心 1mm,§十六 初稿"3.5cm 滞后"
   错;对中闸保留为 8mm 兜底保险)。

## 十六、用户复诉②"每次放的位置不一样"——设计使然+物理散布

`_place_pose` = 箱心 + `bin_grid_offsets` **3 格循环**(防堆叠/防互碰
弹开,2026-10-03 定档:±0.05 时角线互穿会把后放件推离 4.5cm),回收
删除后计数不回退、继续轮转。实测 8 件落点对理论格心偏差 1-19mm
(自由落体+触底翻滚散布,中位 ~4mm)——**不是随机,是 3 格轮转 +
厘米级落点散布**。若用户要"先堆中间格"或更小散布,改动点在
`bin_grid_offsets` 顺序或释放高度,需另行拍板。
