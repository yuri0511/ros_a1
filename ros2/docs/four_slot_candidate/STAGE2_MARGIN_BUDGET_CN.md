# 定量裕量预算：不能闭合

最小0.961172885 mm位于红箱4抬升0.372秒，左指对当前工件的66×66×50 mm包络。SAT指标定义为15条单位分离轴上投影区间间隙的最大值；正值说明该采样姿态分离，不等于真实欧氏距离，也不是连续时间最小间隙。

保守审查应要求：采样分离下界 > 机器人实际姿态/跟踪误差 + 手指误差 + 工件位姿误差 + 碰撞模型误差 + 采样间运动余量 + 检出到停止期间运动余量。各项必须有独立来源，不能重复扣除已膨胀的±8 mm，也不能把未知项设零。
