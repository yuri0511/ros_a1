# 释放全过程证据与单位

URDF两指均为prismatic，q单位m；左右局部轴分别(0,1,0)/(0,-1,0)，URDF限位−0.003..0.040 m、速度限位0.2 m/s。控制接口为effort，发送数值是N，不是mm位置命令。精确定义见finger-joint-definition.json与原URDF。

阶段定义：RELEASING允许原闭合位置−3 mm至候选上界14 mm；进入EXITING前两指必须各达到10–14 mm，此后8–14 mm约束持续到退出确认。不会要求尚未张开的手指一开始就达到8 mm。

候选释放顺序仍是卸荷、1.5 N外推、达到10–14 mm反馈后卸荷0 N；退出时离线所假定范围8–14 mm。不保证0 N能保持位置，未安装一个固定开度来替代物理行为。

本轮增加：释放开始即记录反馈；达到开度后直到物理退出确认均监测两指；同一时间戳不延长新鲜度但越界仍触发；源切换、倒退、超过原观察间隙0.05 sim秒、新鲜度0.5秒失败锁存。无首帧有界等待，不允许首帧缺失获得退出许可。ARM_FAULT后取消动作，任务槽保持。观察器与暂停延迟未物理复验，因此监测通过不代表足够停止距离。
