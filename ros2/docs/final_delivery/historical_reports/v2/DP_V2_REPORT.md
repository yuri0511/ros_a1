# V2模型 DP 与信息条件

主要表为确定的完整观察成本均值情景；耗时与训练奖励目标time+.05×demand-idle分别求解，不把二者最优混称。

| 策略 | 仿真耗时 | 加权代价 | 距最短时间DP | 距加权DP |
|---|---:|---:|---:|---:|
| rule | 168.488 | 174.285 | 4.472 | 4.592 |
| q_v1_prefeed_false | 164.015 | 169.782 | 0.000 | 0.088 |
| q_yuri_history | 164.015 | 169.782 | 0.000 | 0.088 |
| q_v2_demo | 168.488 | 174.285 | 4.472 | 4.592 |
| q_v2_general | 164.015 | 170.001 | 0.000 | 0.307 |
| dp_reward | 164.108 | 169.693 | 0.093 | 0.000 |
| dp_makespan | 164.015 | 170.001 | 0.000 | 0.307 |

V2默认表未胜Rule，均值时间落后最短时间DP4.472s；通用表达到164.015s的最短时间，但不是169.693加权代价的最优。旧Q按新合法动作过滤后也达到164.015s，因此不能宣称新训练击败旧Q。加权DP耗时164.108s，稍长于time-DP，是idle权重的真实取舍，不是数据错误。

DP复用V2全部合法动作与step，包含WAIT、单槽/单pick-owner/每臂状态、完整内部事件相对时间、活动profile及逐色ordinal。不是只枚举颜色顺序。小批次独立无缓存穷举与DP一致，包含强制WAIT和主动WAIT；完整状态缓存不使用Q的ETA离散key。

## 随机场景 oracle 的额外信息

20个独立固定场景中，oracle还知道每个颜色/ordinal将抽到的未来profile及精确事件队列，而Q不知道。默认Q平均距该最短时间oracle约4.354s。这个差距包含额外信息价值，不能全当作Q学习误差；oracle不是普通观测条件下的最优可部署策略。每场景完整记录在EVALUATION_V2.json及ORACLE_GENERAL_AUDIT.json。

均值场景/nominal前缀扣除敏感性/经验随机场景分别归档；不能把确定均值模型DP当作带未知失败和物理碰撞系统的全局最优，也没有求出原POMDP在所有可能真实失败分布下的最优。

## 观测与合法性测试

- 不同未来profile银行在相同当前观察下的state/合法动作相同。
- POST ETA用校准均值而非抽到的真实返回时间；不向Q泄漏未来失败。
- WAIT跳过放置等内部事件，至真实ARM_READY才重新决策。
- 全部评估动作属于资源合法集合；native adapter32条观察重建一致。
- 原table/config不改metadata伪装成schema2；旧Q只是明确标记的Q值迁移参考。
